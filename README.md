# 🧮 Калькулятор пределов

Профессиональный калькулятор для вычисления математических пределов функций с поддержкой сложных выражений и различных типов пределов.

## 🌟 Основные возможности

### 📊 Вычисление различных типов пределов
- **Пределы в конечных точках**: `lim(x→a) f(x)`
- **Пределы на бесконечности**: `lim(x→∞) f(x)`, `lim(x→-∞) f(x)`
- **Односторонние пределы**: `lim(x→a+) f(x)`, `lim(x→a-) f(x)`
- **Пределы тригонометрических функций**
- **Пределы экспоненциальных и логарифмических функций`

### 🔢 Поддерживаемые математические операции
- **Арифметические операции**: `+`, `-`, `*`, `/`, `**` (степень)
- **Тригонометрические функции**: `sin()`, `cos()`, `tan()`, `cot()`
- **Обратные тригонометрические**: `asin()`, `acos()`, `atan()`
- **Экспоненциальные и логарифмические**: `exp()`, `log()`, `ln()`
- **Гиперболические функции**: `sinh()`, `cosh()`, `tanh()`
- **Специальные константы**: `pi`, `E`

### 🛠️ Технические особенности
- **Символьные вычисления** с использованием библиотеки SymPy
- **Автоматическое упрощение** выражений
- **Подробные сообщения об ошибках** с указанием причины
- **Интерактивный режим** работы
- **Поддержка комплексных выражений**
